# Day 10 (Week 2, Day 3): Construction Material Properties Comparison

Goal: Build a visual comparison dashboard of key engineering properties 
(density, compressive strength, elastic modulus, relative cost) across 
common construction materials — Steel, Concrete, Timber, Aluminum.

## What I did
- Compiled representative property values for 4 common materials
- Created a 2x2 dashboard using matplotlib subplots
- Calculated strength-to-weight ratio as an extra engineering insight

## Files
- `material_comparison.py` — main script
- `material_comparison.png` — output dashboard

## Result
Steel has the highest absolute strength and stiffness, but Aluminum 
and Timber have better strength-to-weight ratios — useful insight for 
applications where weight matters (e.g. lightweight structures).
