# Day 4: Rebar Weight & Cost Calculator (Automation)

Goal: Automate a common manual estimation task — calculating total 
rebar weight and cost from a bar bending schedule / BOQ list.

## What I did
- Implemented the standard rebar unit weight formula (d²/162)
- Built a script that processes multiple bar diameters and quantities
- Auto-calculates total weight, cost, and tonnage

## Files
- `rebar_calculator.py` — main script

## Result
Given a list of rebar diameters, lengths, and quantities, the script 
automatically generates a summary table with weight and cost per bar 
type, plus totals — saving manual calculation time on real projects.
