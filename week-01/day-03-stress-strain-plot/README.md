# Day 3: Stress-Strain Curve Visualization

Goal: Plot and compare stress-strain curves for steel, concrete, and 
aluminum to visualize their mechanical behavior differences.

## What I did
- Created idealized stress-strain data for 3 materials
- Plotted all curves on one graph using matplotlib
- Compared yield behavior, stiffness, and failure characteristics

## Files
- `stress_strain_plot.py` — main script
- `stress_strain_comparison.png` — output graph

## Result
Steel shows clear yield point and strain hardening. Concrete is brittle 
with a parabolic curve up to peak compressive strength. Aluminum shows 
gradual yielding with no sharp yield point.
